== Scope

These preliminary tests used the working source tree based on commit
`97192d1`, with the standalone installation changes and the previous 1.3.0
version identity. Source archives exclude unrelated
untracked chat exports and old `.rock` files. Remote checkouts, installations
and artifacts use dedicated temporary directories; system packages and shell
profiles are unchanged.

This is supplemental physical-host evidence for the 1.4.0 plan, not a claim
that the complete release matrix has passed. The required gates remain those
in xref:TESTING.adoc[Testing].

The standalone suite installs into a path containing spaces, rejects repeat
installation without overwriting a sentinel file, moves the installation,
runs both wrappers from an unrelated directory, analyzes/traces a two-module
application, loads the API, builds both artifact forms, and executes them with

checks symlink-ancestor refusal and staging cleanup when the selected
interpreter fails the final installation probe.

listed by `mssh`.

== Findings

* macOS's default temporary directory traverses the system `/var` symlink.
  The installer now accepts the root-owned `/var` and `/tmp` aliases through
  the existing filesystem ownership check, while still rejecting user-created
  symlink ancestors. The final macOS run passed after this correction.
* Passing quoted `.cmd` paths as CRT-style arguments to `cmd /c` broke the
  initial Windows test harness. The standalone test now invokes Windows
  command wrappers through native PowerShell, including paths with spaces.
* The legacy host cannot validate the documented Windows install/build
  contract until PowerShell and the native development prerequisites are
  provisioned. Its successful version/API-loading probes do not exercise
  filesystem analysis, installation or compilation.

== Reproduction and remaining release gates

On a prepared native host, from the source root:

[source,bash]
----
lua test/standalone_install.lua
lua test/cli_split_smoke.lua
----

Set `LUAI_TEST_LUA` and `LUAI_LUA_PREFIX` when using a private Lua toolchain.
POSIX custom prefixes may also need `PKG_CONFIG_PATH`. On native Windows,
use native filesystem paths even when SSH enters through Cygwin.

Raw logs and production-file SHA-256 identities are retained locally under
`.tmp/real-world-2026-09-22/`. The source archive was built from current file
contents, including the new files, rather than `git archive HEAD` (which
would omit these uncommitted changes). Modified installer/test files were
copied again before final reruns.

At the time of these preliminary tests, the complete GitHub Actions
Linux/Windows five-ABI release matrices and native Linux x86 gate had not yet
run for a release commit. Their scripts include the standalone suite; see
the https://github.com/Water-Run/luainstaller/releases/tag/v1.4.0[release notes]
for the subsequent exact-commit CI results. Windows 5.1/5.2/5.3/5.5, macOS
versions other than the tested 5.4.8, FreeBSD, Android/Termux and Windows XP
remain outside this iteration's physical-host evidence.
