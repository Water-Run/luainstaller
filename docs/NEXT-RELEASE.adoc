== Scope and current state

The version identity is 1.4.0. The main objective of this release is to make
source installation and library/CLI use first-class without requiring
LuaRocks. Existing LuaRocks installation and the two CLI grammars remain
supported.

Included in 1.4.0:

* Source CLI entry points for both command grammars, plus a root library loader.
* One offline Lua installer for POSIX and native Windows, with dedicated
  prefixes, relative wrappers, staging, refusal to overwrite, and license/docs.
* An integration suite covering relocation, API, analysis/trace, both artifact
  forms and execution with Lua search paths cleared and an empty runtime PATH.
* A dedicated installation guide and retained LuaRocks installation coverage.

Physical-host validation now passes on local Fedora, Debian, Linux ARM64
(all five Lua ABIs), macOS ARM64 and Windows Server 2025. The legacy Windows
host is blocked by PowerShell 1.0 and missing native build prerequisites;
see the dated report below for the exact scope of each result.

== Release checklist

The 1.4.0 release is subject to these gates. Exact-commit CI evidence is linked
from the https://github.com/Water-Run/luainstaller/releases/tag/v1.4.0[release notes].

* Run the new standalone suite for all five supported Lua ABIs on Linux and
  Windows/MSVC, alongside the existing required CI gates. LuaRocks continues
  to be required for the LuaRocks-specific gate only.
* Record physical-host outcomes separately for Linux x86_64/ARM64, macOS
  ARM64, modern Windows and the legacy Windows environment. A missing
  compiler/header/runtime is a blocked build test, never a successful build.
* Check installation and CLI/API use from outside the source checkout, paths
  with spaces, relocation, a failing install, and repeat-install refusal.
* Update API/CLI version strings, rockspec identity and tag references together;
  lint the new rockspec and run documentation/version contracts.
* Publish only after the Linux/Windows Lua matrix and native Linux x86 gate
  described in xref:TESTING.adoc[Testing] pass for the release commit.

Supplemental physical evidence for this iteration is recorded in
xref:REAL-WORLD-2026-09-22.adoc[the dated environment report]. Logs are local
test artifacts; do not commit machine credentials or old generated packages.

== Later work

Prebuilt tool archives, OS package-manager recipes, shell completions and an
in-place upgrade/uninstall manager are separate follow-up work. Prebuilt
luainstaller executables alone would not supply the compiler, Lua headers or
matching native dependency ABI required to package an application. Define
that toolchain contract before promising a zero-prerequisite installer.

Do not broaden platform support claims from simulated or cross-compiled tests
alone. Retain the capability-specific limits in
xref:PLATFORMS-NATIVE-LIMITS.adoc[Platforms and native modules].
