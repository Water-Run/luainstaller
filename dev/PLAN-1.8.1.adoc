= luainstaller 1.8.1：命令正确性修复
:toc:
:sectanchors:

以 1.8.0 为基线，优先修复命令解析、数据输出和诊断中的可复现问题。
审计与回归记录见 xref:AUDIT-1.8.x.adoc[质量审计]。

== 范围

* 核对两个入口的每个命令、别名、值参数、布尔开关、重复与冲突输入。
* 保持 `--` 后应用参数的内容和顺序；展示选项不干预应用参数。
* 检查 JSON 的解析有效性、数值与字符串完整性、错误和警告契约。
* 保留完整路径与诊断，处理窄终端、Unicode 和控制字符。
* 检查帮助、日志和失败输出，保持 classic 与 modern 的操作结果、退出码一致。
* 将新回归接入 Linux、Windows/MSVC、官方 Lua 和 LuaJIT 门禁。

== 推进与验收

. 在固定基线上记录失败输入、实际结果和预期行为，再修复实现。
. 专项回归覆盖两种 CLI 和公共入口；已有正确性、配额、恢复和安装回归继续执行。
. 完成本地全量套件、必需原生矩阵和可连接补充平台的完整验收。
. 同步版本、双语文档、手册和安装材料；记录真实通过、失败和受阻项。
. 完成安装升级与产物验收后，将遗留的终端、进程和交付问题带入
  xref:PLAN-1.8.2.adoc[1.8.2]，保留明确的问题编号和处理依据。

完成条件：确认的高优先级命令问题关闭；发布候选的全量门禁和安装验收通过。
测试覆盖以实际执行为准，不从现有绿色 CI 推导新场景正确。
