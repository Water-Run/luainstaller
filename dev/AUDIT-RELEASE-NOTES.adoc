= GitHub Release 文档重写审计
:sectanchors:

== 结果

2026-11-12：已按用户要求重写全部 14 个现有公开 Release 的正文，
统一为 `Overview` 和 `Details`。概述用一句话说明核心更新，详细说明按功能、
修复和相应使用条件逐条列出，沿用英文。后续写作规则同步到根目录 AGENTS.md。

1.7.0 概述明确以新增 LuaJIT 2.1 支持为主线；详细说明列出运行时选择、
三种产物模式、显式 FFI 库、内置模块、静态库要求、构建配置匹配和 JIT 开关。
1.5.0 的构建依赖简化、1.6.0 的免解包单文件与 MoonScript、1.8.0 的命令行呈现
也分别放到对应版本的概述中。

1.6.1 和 1.7.0 标签内的 changelog 尚未设同名版本标题，因此同时以实际差异及
1.7.0 的 docs/LUAJIT.adoc 核实功能归属；没有把旧 Unreleased 条目直接当成该版新增功能。

== 校验与留档

* 逐页检查两节结构、单句概述和具体条目，LuaJIT 新增支持归属 1.7.0。
* 版本指南链接指向相应发布标签，链接的仓库文件实际存在。
* 使用仅含 body 的请求更新正文，逐页回读，并最终再次读取全部 Release。
* 14 份公开正文与审核稿完全相同。标题、标签、发布状态与时间、附件 ID、
  文件名、大小和 SHA-256 digest 均与改写前快照相同。
* 根目录写作约定改为所有版本统一采用 Overview / Details；用户指南和版本产物
  沿用各自现有发布内容。
