== 1.8.1 已复现问题

[cols="1,3,3",options="header"]
|===
|编号 |问题与影响 |修复与回归
|Q81-01
|展示参数越过 `--`，等号形式的应用参数被拆分或丢失，改变运行时发现所执行的程序输入。
|保留分隔符后的原始序列；`test/cli_boundaries.lua` 覆盖两个入口与展示选项。
|Q81-02
|等号形式的显式值仍被当作选项；冲突标量和发现模式静默覆盖。
|区分显式值与下一个选项，冲突在操作前返回参数错误。冲突拒绝属于接口收紧。
|Q81-03
|`<command> --help` 失败，未知帮助主题却返回成功。
|帮助识别尊重值参数和 `--`；非法主题返回非零状态。
|Q81-04
|现代输出截断完整路径；日志等文本可原样输出不可信终端控制序列。
|保留字段全文，转义控制字节；普通文本的字段与退出码保持兼容。
|Q81-05
|JSON 有限数值丢失精度、非法 UTF-8 字节原样输出，日志恢复告警落到对象之外。
|数值往返、有效字符串编码和结构化告警均有独立行为回归。
|Q81-06
|命令展示套件使用 POSIX 专属的 env/chmod/sleep，未进入 Windows 矩阵，掩盖覆盖缺口。
|改为跨平台进程与文件接口；统一接入 Windows、POSIX 和 LuaJIT 套件列表。
|===

Q81-01 至 Q81-05 的基线失败已在官方 Lua 和 LuaJIT 下分别保留，修复后的专项通过。
完整平台和安装验收仍在进行，尚未形成最终质量结论。过程日志保存在任务专用目录。
