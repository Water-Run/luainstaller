= luainstaller 1.8.2：终端、进程与交付收尾
:toc:
:sectanchors:

以通过验收的 1.8.1 为基线，继续修复平台和交付问题，为 1.9.0 建立稳定基线。
本版不实现 o1/o2/o3。审计与回归记录见 xref:AUDIT-1.8.x.adoc[质量审计]。

== 范围

* 检查真实 TTY、重定向、CI、Windows 控制台和低能力终端的颜色与进度策略。
* 验证进度动画的刷新、资源上限、退出、中断和父进程死亡后的清理。
* 检查源码、独立安装、LuaRocks 安装中的命令、许可证、文档布局与本地链接。
* 检查三种产物模式、LuaJIT/FFI、MoonScript、重定位和清空运行环境后的执行。
* 复审 1.8.1 修复及相邻分支，补充真实 Windows 与 POSIX 行为回归。

== 平台与完成条件

必需门禁为官方 Lua 五 ABI 的 Linux 与 Windows/MSVC 矩阵、原生 Linux x86，
以及固定源码的 LuaJIT 五配置矩阵。补充平台覆盖可用的 Debian、Rocky、
Linux ARM64、macOS、FreeBSD、Android/Termux 和旧 Windows。

每个目标记录运行时、编译器、套件、退出码与完整日志；缺少入口或编译环境的目标
记为受阻，并继续解决前置条件。交叉编译或后端模型不替代原生执行。

完成前复核：

* 两轮确认的问题均有失败证据、修复和行为回归，高优先级问题关闭。
* 全量套件与平台矩阵通过；受阻目标未被计作成功。
* 独立安装、升级、实际附件和无源文件目标的产物运行通过。
* 两种命令的稳定文本/JSON、终端恢复和错误状态可依赖。
* 仓库只保留 main，已完成计划移除，证据保存在审计和任务记录。
* 1.9.0 可从这一基线开展产物运行效率测量，且有明确的关闭优化对照。
