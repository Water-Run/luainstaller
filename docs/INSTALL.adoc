LuaRocks isn't required. You can run `luainstaller`
straight from the source folder, or install a copy into a folder of your
own. Neither needs administrator rights or a network connection.

NOTE: Building needs a Lua interpreter, a matching Lua library and a C
compiler. Lua headers aren't needed. The installer doesn't install these
or your application's dependencies.

== Run from the source folder

Download and unpack the source, then:

[source,bash]
----
lua bin/luai.lua -v
lua bin/luai.lua -b path/to/app/main.lua -o build/app
----

`bin/luainstaller.lua` gives you the subcommand style. Both work from any
directory as long as you give their full path.

To use the library, put the source folder on `package.path` first:

[source,lua]
----
package.path = "/path/to/luainstaller/?.lua;" .. package.path
local luainstaller = require("luainstaller")
----

== Install a copy

Pick a folder that doesn't exist yet. Its parent must exist.

Linux and macOS::
+
[source,bash]
----
lua tools/install.lua --prefix "$HOME/luainstaller"
export PATH="$HOME/luainstaller/bin:$PATH"   # add to your shell profile
luai -v
----
+
For fish: `fish_add_path $HOME/luainstaller/bin`

Windows (compiler command prompt)::
+
[source,bat]
----
lua tools\install.lua --prefix "%USERPROFILE%\luainstaller"
set "PATH=%USERPROFILE%\luainstaller\bin;%PATH%"
luai -v
----
+
The commands are `luai.cmd` and `luainstaller.cmd`. Use the compiler's
command prompt, or put MinGW-w64 on `PATH`. PowerShell isn't needed,
including on Windows XP.

The installed commands remember which `lua` ran the installer. To pin a
different one, pass `--lua /full/path/to/lua` when installing, or set
`LUAI_LUA` later.

[IMPORTANT]
====
That interpreter must be the same Lua version as the library you build
with. A 5.4 interpreter with a 5.3 library won't work.
====

== Move, upgrade or remove

[horizontal]
Move:: Move the whole folder and update `PATH`. The commands find their
files relative to themselves.
Upgrade:: Install the new version into a new folder, try it, then switch
`PATH` over.
Remove:: Delete the folder and take it out of `PATH`. Nothing else was
changed on your system.

TIP: Put the installation's `bin` folder on `PATH` rather than
symlinking single commands out of it.
