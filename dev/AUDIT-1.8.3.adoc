=== Q183-06 最小独立复现

从仓库根部执行；`WORK` 是新建的私有工作目录，保留输出供复核：

[source,bash]
----
WORK=$(mktemp -d /tmp/luainstaller-varargs-XXXXXX)
printf '%s\n' 'print(select("#", ...), ...)' > "$WORK/main.lua"
lua "$WORK/main.lua" alpha '' --literal
lua bin/luai.lua -b --dir "$WORK/main.lua" -o "$WORK/app"
"$WORK/app/app" alpha '' --literal
----

预期两次应用运行的参数数量均为 3；当前直接运行是 3，产物是 0。
解包、免解包、runtime API、内嵌 runtime 和发现路径的完整夹具为证据目录中的
`probe-varargs.lua`。以新的空目录作为它的第一个参数，不能覆盖已有 onefile 路径。
发现对照显式设置夹具的 `LUA_PATH`，避免把普通模块搜索路径失败误判为参数缺陷。
